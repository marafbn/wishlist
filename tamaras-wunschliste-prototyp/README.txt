TAMARAS WUNSCHLISTE - LOKALER PROTOTYP

Dateien:
- index.html: Uebersicht mit Wunschkarten und Hintergrundfoto
- quiz.html: dreistufiger Geschenk-Konfigurator
- admin.html: lokaler Admin-Bereich zum Anlegen, Bearbeiten, Loeschen und Bebildern von Wuenschen
- styles.css: Farben und Layout
- data.js, app.js, quiz.js, admin.js: Daten und Interaktionen
- images/: dein Logo und das hochgeladene Hintergrundbild

START IN VS CODE:
1. Entpacke den ZIP-Ordner.
2. Oeffne den Ordner in VS Code.
3. Installiere bei Bedarf die Erweiterung Live Server.
4. Rechtsklick auf index.html > Open with Live Server.
5. Admin-Seite ueber den Admin-Link oeffnen. Beim ersten Besuch ein Passwort festlegen.

WICHTIG:
Das ist ein lokaler Prototyp. Wuensche, Bilder und Reservierungen werden in localStorage im jeweiligen Browser gespeichert. Andere Personen auf anderen Geraeten sehen diese Aenderungen noch nicht. Die Admin-Anmeldung ist ebenfalls nur ein lokaler Prototyp und kein echter Sicherheitsschutz. Fuer gemeinsame, private Reservierungen braucht die spaetere Online-Version ein Backend mit Datenbank und echter Anmeldung.

Wunschbilder:
Im Admin-Bereich kannst du pro Wunsch eine Bilddatei hochladen. Sie wird fuer diesen lokalen Prototyp verkleinert und im Browser gespeichert. Verwende fuer Tests eher kleinere Fotos.
